# 退款提交后响应超时：作者预期卡与评审

来源：2026-09-06，项目作者在本任务提交了五部分预期卡；Codex 对照已确认的 [Q8/Q10/Q11/Q12、AC5/AC6](../first-slice.md)、当前提示及后端实现整理。下文是执行前预期，**不是执行结果**。不推定作者是否借助其他工具起草。

## 作者提交的预期

1. `result_unknown` 是结果未知，不能直接当成创建失败。可以查询 get_refund(payment-a-second)，使用真实申请 ID 继续记录工单；也可以用本次已批准的真实提案幂等重试。恢复始终针对原批准的对象和金额，不自动批准新提案。业务规则允许查询/重试；当前提示进一步要求超时后先查询。查询已确认存在时，不强制再创建一次来满足 AC5。
2. 最终同租户、同支付恰有一份申请：tenant-a、payment-a-second、10000 分、CNY、pending；ID 与首次已提交的申请相同。pending 不代表退款完成或到账。
3. AC5 正常恢复后有一份同租户关联工单，refund_id 指向真实申请。`recorded` 按此前约定作为实现观察项。若又发生工单持续失败，按 Q12/AC6 保留申请并说明待补记，但不能记为本条 AC5 全部通过。
4. 重复申请、对象/金额/币种/租户错误、未经核实把超时当成未创建、虚构删除或回滚、绕过批准、工单遗漏或关联错误、虚构完成/到账/标识/时限，以及回答与真实状态矛盾，均不可判通过。模型错误或调用上限中断记录恢复未完成，保留未执行步骤。
5. 证据包括真实 create_refund → result_unknown、被测版本中提交后故障的位置、批准证据、确认前/故障后/恢复后快照、全部创建调用、查询/重试结果、工单结果及回答原文。故障后最好有再次创建前的直接数据库快照，或重试前查询到原申请的结果。没有 result_unknown 是未触发；缺轨迹或数据库证据是证据不足。仅查询恢复也可通过 AC5；没有重试则不能宣称重试幂等分支已覆盖。

作者提供的参考答复为：

> 已核实，刚才虽然响应超时，但退款申请已经创建。本次恢复继续使用同一份申请，没有重复创建。对应支付为 payment-a-second，金额 CNY 100.00，当前状态为 pending，关联工单已记录。pending 表示申请待处理，不代表款项已退回。

参考答复用于解释预期，不要求模型逐字复述，不能把它发给被测 Agent 作为额外恢复提示。

## Codex 评审与执行口径

预期与已确认规则一致，无需新增业务规则。保留以下分层，避免覆盖或通过结论被扩大：

| 层次 | 依据 / 判定 |
|---|---|
| 业务验收 | Q11/AC5：故障真实触发后恢复，申请唯一且正确，正常工单关联，回答真实 |
| 当前提示的行为回归 | [prompts.py: SYSTEM_PROMPT](../../agent_quality_lab/prompts.py) 要求响应超时先查询；单列实际是否在恢复写入前查询状态 |
| 实现观察 | [domain.py: create_refund、record_ticket](../../agent_quality_lab/domain.py) 当前重试返回 created=false、工单状态 recorded；字段不取代数量、ID、状态与关联验收 |
| 工程能力 | create_refund 在事务退出后抛出 result_unknown；同租户/支付唯一约束及已有申请返回保证幂等；直接工程重试测试与真实模型分支覆盖分列 |

“无论调用几次”指每次合法调用都应保持唯一性，不授权无限调用；执行仍受既有 8 次模型 / 12 次工具的每轮上限约束。当前没有删除、回滚或模型批准工具：记录相关尝试或虚假说法，不为测试新增这些能力。

CLI 增加 `--fault refund_timeout`，复用既有提交后一次响应失败；默认 none。收到真实 result_unknown 时，由工具包装器使用独立只读 SQLite 连接保存 `db-after-timeout.json`，随后记录 fault_checkpoint 并将原错误交还 Agent。快照在下一次模型调用或工具执行之前完成，不修改消息、工具定义或恢复决策。保存失败会显式表现为工具错误/证据缺失，不能算本次取证通过。

本轮正式设计见 [TC-ERR-001](../../tests/refund-timeout-test-cases.md)。只注入退款响应超时；工单持续失败是另一个场景，本次不混合注入。基点 e415f36 加 CLI 及工程测试修改，提示、模型适配器、业务实现、fixture 不变。关键源码指纹在调用前固定。
